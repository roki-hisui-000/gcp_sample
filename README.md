# Google Cloud Platform デプロイサンプル

## 概要

本プロジェクトは、GCP（Google Cloud Platform）上で稼働、デプロイ手順を確立することを目的とする。

## システム構成

簡単なWebシステムとする。

### クライアント

- 画面下部にメッセージの入力項目と送信ボタンを配置する。
- メッセージを入力して送信ボタンをクリックすると、入力内容をサーバーに送信する。
- 画面上部にはメッセージの表示領域を配置する。
- サーバからメッセージを受信した場合は、表示領域にその内容を表示する。
  - 上が最新のメッセージを表示して、下になるほど古いメッセージを表示する。

### サーバ

- 初期アクセス時は、`クライアント`に記載した内容を画面を返す。
- メッセージ受信時は、メッセージにサーバ側の現在時刻（JST）を付与して返す。
  - 例："Hello"を受信時、"2026/09/19 11:23:56 Hello"を返す。

## アーキテクチャ

- サーバは`Node.js`で構築する。
- クライアントは`React`で構築する。
- Dockerコンテナで稼働する。 
  - Dockerイメージを作成する手順を確立する。
