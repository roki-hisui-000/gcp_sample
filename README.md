# Google Cloud Platform (GCP) デプロイサンプル Web アプリ

本プロジェクトは、GCP（Google Cloud Platform）における「2コンテナ ＋ インメモリDB（Valkey）」構成でのコンテナビルド、データ永続化、セキュアなサービス間連携、およびデプロイ手順の確立を目的としたWebアプリケーションのサンプルです。

---

## 🌟 主な機能・UX仕様

1. **新規名前登録画面 (新規)**
   - 初めて利用するユーザーが名前を登録する画面（プロトタイプのためパスワードは不要）。
   - 入力された名前はバックエンドを介して **Valkey（データベース）に永続化** されます。
   - 同名がすでに登録されている場合は、エラーメッセージを表示して重複登録を防止します。
   - 登録完了後、自動的に初期画面（ログイン画面）へ遷移します。

2. **初期画面 (ログイン画面)**
   - 登録済みの名前を入力してチャットを開始（セッションを確立）する画面。
   - 未登録の名前を入力した場合はエラーメッセージを表示し、チャットへの遷移を拒否します。
   - 「新規名前登録はこちら」のリンクから名前登録画面へ切り替えることができます。

3. **チャット画面**
   - 名前が登録・ログイン済みのセッションでのみアクセス可能。
   - 画面下部の入力フォームからメッセージを送信すると、サーバー側の現在時刻（JST）と送信者名が付与されて即座に返却表示されます。
   - 最新のメッセージが上に表示されます。

---

## 🏗 システム構成 & アーキテクチャ

本システムは、セキュリティ、CORS回避、スケーラビリティを高めるため **「2コンテナ ＋ 1インメモリDB」** の3層構造で構築されています。
